## Спецификация требований для Chatty (второй релиз)

### О проекте

Chatty — приложение для изучения иностранных языков. В рамках второго релиза планировалось добавить две новые функции: карточки для запоминания слов и просмотр обучающих видео.

### Задача

Доработать спецификацию требований к ПО (SRS) под новую функциональность второго релиза.

### Результат

**Для функции карточек:**

- Дополнена спецификация функциональными требованиями

**Для функции просмотра видео:**

- Обновлена диаграмма UML Use Case
- Добавлены новые табличные варианты использования
- Написаны функциональные требования
- Заполнены разделы спецификации: атрибуты качества, бизнес-правила, глоссарий

### Инструменты

UML, Use Case, draw.io, Google Docs
